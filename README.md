# CLEO Library for GTA III & Vice City (Windows PC)

CLEO Library is an open-source extensible plugin for the Grand Theft Auto series by Rockstar Games, allowing the use of thousands of unique mods which change or expand the gameplay. You may find more information about CLEO on the official website https://cleo.li.

This repository provides CLEO for **GTA III** and **GTA: Vice City**. For **GTA San Andreas** support, visit the [CLEO 5 repository](https://github.com/cleolibrary/CLEO5).

## Installation

Download the archive from the [releases page](https://github.com/cleolibrary/III.VC.CLEO/releases) then extract the files into the game directory (where `gta3.exe` or `gta-vc.exe` are located).

Recommended game version is 1.0.

### GTA III

The archive creates the following files:

- `III.CLEO.asi` (core library)
- `cleo\` (CLEO script directory)
- `cleo\cleo_plugins\III.ClipboardControl.cleo` (OS clipboard support)
- `cleo\cleo_plugins\III.FileSystemOperations.cleo` (file system plugin)
- `cleo\cleo_plugins\III.IniFiles.cleo` (INI files support)
- `cleo\cleo_plugins\III.IntOperations.cleo` (additional math operations)
- `cleo\cleo_plugins\III.MemoryModule.cleo` (DLL handling)

### Grand Theft Auto: Vice City

The archive creates the following files:

- `VC.CLEO.asi` (core library)
- `cleo\` (CLEO script directory)
- `cleo\cleo_plugins\VC.ClipboardControl.cleo` (OS clipboard support)
- `cleo\cleo_plugins\VC.FileSystemOperations.cleo` (file system plugin)
- `cleo\cleo_plugins\VC.IniFiles.cleo` (INI files support)
- `cleo\cleo_plugins\VC.IntOperations.cleo` (additional math operations)
- `cleo\cleo_plugins\VC.MemoryModule.cleo` (DLL handling)

> All plugins are optional, however they may be required by various CLEO scripts.

If installed correctly, the game menu will display the text "CLEO" and the version number in the bottom left corner of the screen.

## CLEO Scripts

CLEO allows the installation of 'CLEO scripts', which often use the extension `.cs`. These third-party scripts are entirely user-made and are in no way supported by the developers of this library. While CLEO itself should work in a wide range of game installations, individual scripts are known to have their own compatibility restrictions and can not be guaranteed to work.

CLEO scripts can be found on Grand Theft Auto fansites and modding sites such as:

- **GTA III:** https://libertycity.net/files/gta-3/mods/scripts/
- **Vice City:** https://libertycity.net/files/gta-vice-city/mods/scripts/
